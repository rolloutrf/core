# Фронтенд-разработчик

Дизайн для основных экранов Роллаута уже готов. Очень ждём в команду нескольких человек, которые помогут превратить макеты в полноценный react-конструктор для приложений.

В Роллауте есть задачи для любого уровня — точно сможете попробовать новое и улучшить свои навыки. А ещё познакомитесь с экспертами по созданию цифровых продуктов и поучаствуете в разработке интерфейсов с эталонным UI для финтеха и ecom. Такой опыт пригодится в любом портфолио.

## Чем предстоит заниматься

- Разрабатывать библиотеку UI-компонентов на React
- Тестировать и отлаживать разработанные решения

## Будет здорово, если вы

- Работаете с экосистемой React и дизайн-системами. Мы используем shadcn — если уже с ней сталкивались, будет проще освоиться
- Ориентируетесь в Фигме: мы передаём и храним макеты именно там
